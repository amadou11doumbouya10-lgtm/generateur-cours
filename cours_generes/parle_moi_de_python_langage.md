# Cours de Python : Introduction et Définition
Python est un langage de programmation de haut niveau, interprété et orienté objet. Il est créé dans les années 1990 par Guido van Rossum et est maintenant géré par la fondation Python. Python est connu pour sa syntaxe simple et lisible, ce qui en fait un langage idéal pour les débutants et les experts.

## Pourquoi Utiliser Python ?
Python est utilisé dans de nombreux domaines, tels que :
* Le développement web (Django, Flask)
* L'analyse de données (Pandas, NumPy, Matplotlib)
* L'apprentissage automatique (TensorFlow, Keras)
* La robotique (ROS)
* La sécurité informatique

Voici quelques cas d'usage concrets :
* Créer un site web avec Django
* Analyser des données avec Pandas et NumPy
* Développer un modèle d'apprentissage automatique avec TensorFlow

## Installation et Prérequis
Pour installer Python, vous pouvez suivre ces étapes :
1. Allez sur le site officiel de Python et téléchargez la version la plus récente.
2. Suivez les instructions d'installation pour votre système d'exploitation (Windows, macOS, Linux).
3. Installez un éditeur de code (PyCharm, Visual Studio Code, Sublime Text).

## Concepts Fondamentaux
Voici quelques concepts fondamentaux de Python :
* Les variables : `x = 5` (affecte la valeur 5 à la variable x)
* Les types de données : `int`, `float`, `str`, `list`, `dict`
* Les opérateurs : `+`, `-`, `*`, `/`, `==`, `!=`
* Les structures de contrôle : `if`, `else`, `for`, `while`
* Les fonctions : `def nom_de_la_fonction():`

### Exemples de Code
```python
# Exemple 1 : Afficher "Bonjour, monde !" à l'écran
print("Bonjour, monde !")

# Exemple 2 : Demander le nom de l'utilisateur et l'afficher
nom = input("Quel est votre nom ? ")
print("Bonjour, " + nom + "!")

# Exemple 3 : Calculer la somme de deux nombres
a = 5
b = 3
somme = a + b
print("La somme de", a, "et", b, "est", somme)

# Exemple 4 : Utiliser une structure de contrôle (if)
x = 5
if x > 10:
    print("x est supérieur à 10")
else:
    print("x est inférieur ou égal à 10")

# Exemple 5 : Utiliser une fonction
def dire_bonjour(nom):
    print("Bonjour, " + nom + "!")

dire_bonjour("Jean")
```

## Erreurs Courantes et Comment les Éviter
* Erreur de syntaxe : vérifiez que votre code est correctement écrit et que les indentations sont correctes.
* Erreur de type : assurez-vous de utiliser les types de données corrects pour vos variables.
* Erreur de logique : testez votre code pour vous assurer qu'il fonctionne comme prévu.
